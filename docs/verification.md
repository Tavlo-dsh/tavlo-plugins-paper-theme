# 全局纸面主题验证

本页记录 **0.1.0** 的历史验证。当前 **0.1.2** 的配色、实际验证与截图见 [新版记录](palette-refinement-0.1.2.md)。旧版截图已从源码目录清理，历史测试结果继续保留。

验证日期：2026-11-17。宿主为实际安装的 **DSH 0.2.2-rc.1**，Windows x64、Node.js 24.18.1、Microsoft Edge 157.0.4341.60，无头 Chromium Web renderer。核对了发布版接口，未修改 DSH 安装文件。

## 隔离与证据

浏览器脚本为每次运行创建独立临时目录及 `DSH_HOME`，安装本地 npm tarball，使用随机本地端口和新的浏览器 context。测试没有复制用户日常配置、任务、会话或 API Key。对话正文为本项目编写的 v4 合成会话，仅用于宿主 Markdown/代码块渲染；没有请求模型。测试自动关闭隔离页面的首次登录提示，不执行登录。

- [浏览器机器报告](browser-verification.json)：主题独立安装、组合使用、宿主重启、卸载检查及发布版参考文件 SHA-256。
- [任务独立安装报告](tasks-standalone-verification.json)：另一全新 home 只安装任务包，从未安装主题包，创建任务并检查宿主浅深模式。
- [回归测试与来源审查结果](test-results.json)：76 项任务测试、10 项新主题测试、60 个固定上游文件与 MIT/纹理核验。
- [颜色对比度抽样](contrast-samples.json)：16 组语义前景/背景在浅深模式的相对亮度比值。

最终浏览器断言全部通过，未捕获异常和 console error 均为零。报告末尾的源文件哈希收集最初使用了一个发布包中不存在的独立 Shiki CSS 路径；发布版实际将样式编译进 `ui-theme/lib/client.js`。已单独补齐正确文件哈希，过程记录在机器报告 `reportAssembly` 中，没有修改或忽略浏览器断言。

最终交付包与浏览器测试包的运行时文件逐字节比较，结果及完整包清单、SHA-256 保存在仓库 `artifacts/paper-theme-20261117/package-verification.json`。测试包运行后仅补齐文档、报告和截图，再生成交付包。

## 复现

在两个插件目录分别执行 `npm install`、`npm test`、`npm pack`。浏览器脚本仅在源码目录提供，不进入安装包。以下从主题目录运行；将三个路径换成本机已安装文件，不需要在线脚本或 CDN：

```powershell
$env:DSH_CLI = 'F:/soft/nodejs/node_global/node_modules/@deepseek-ai/dsh/lib/bin.js'
$env:PLAYWRIGHT_MODULE = '<本机 playwright/index.mjs 的绝对路径>'
$env:BROWSER_EXECUTABLE = 'C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe'
node scripts/verify-browser.mjs ./dsh-plugin-paper-theme-0.1.0.tgz ../tavlo-plugins-tasks/dsh-plugin-tasks-0.1.0.tgz
node scripts/verify-task-standalone.mjs ../tavlo-plugins-tasks/dsh-plugin-tasks-0.1.0.tgz
```

脚本在 finally 中关闭自己启动的宿主与浏览器。临时 home 保留供排查，日志可能包含隔离宿主登录链接，因此不复制到文档或安装包。普通主题使用不需要这些开发脚本或 Playwright。

## 已知限制与未验证项

- 只承诺 DSH 0.2.2-rc.1 Web renderer。本轮未测原生桌面外框、macOS/Linux、其他浏览器内核或其他 DSH 版本。
- 没有执行在线模型生成、真实账号登录或外部工具任务。任务启动恢复与状态同步由原有自动化回归验证，不能把本轮截图当作端到端在线模型验收。
- 没有重新测量 100/500 张卡片性能；历史强制纸面基线不代表当前版本。
- 16 组 token 浅深对比度均不低于 4.5:1，最低样本为 4.77:1。未做完整屏幕阅读器、系统高对比模式和所有语法语言的可访问性认证。
- 使用宿主语义变量的区域随主题变化；写死颜色的第三方 UI 或宿主插图不保证全部覆盖。其他 token 插件可按注册顺序覆盖同名变量。
- UI 禁用/卸载清理已实际验证；命令行卸载说明沿用宿主 CLI，正在运行的页面仍应按宿主提示刷新。
