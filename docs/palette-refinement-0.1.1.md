# 0.1.1 配色调整

本文为历史记录；当前外观与截图见 [0.1.2 配色与纸张层次](palette-refinement-0.1.2.md)。

根据实际使用反馈，0.1.0 的米黄与灰绿铺满侧栏、背景和控件，整体显得沉闷。0.1.1 改用明亮纸白、中性灰和石墨文字，减少大面积有色底面，保留少量绿色交互强调。

| 区域 | 浅色 | 深色 |
| --- | --- | --- |
| 对话画布 | `#fdfdfc` | `#202327` |
| 输入框与弹层 | `#ffffff` | `#2a2e33` |
| 侧栏 | `#f6f7f8` | `#25292e` |
| 正文 | `#30353b` | `#e7eaee` |
| 交互强调 | `#3c745b` | `#9dccb6` |
| 代码区 | `#f6f7f9` | `#1c2025` |

新增 `surface` 与 `bubble` token，使宿主控件和消息气泡采用中性色。任务仍使用自己的纸张 `sheet` 与桌面 `desk`，保留原有纹理、胶带和高亮。此次修改仅涉及主题色板、宿主 token 映射、设置文案与版本号，没有改动任务业务或主题生命周期。

```powershell
dsh plugin --profile web add ./dsh-plugin-paper-theme-0.1.1.tgz
```

更新后刷新 DSH 页面；若宿主尚未载入新模块，再重启 DSH。沿用相同设置命名空间，已经选择的纸面/默认偏好继续保留。新安装仍默认关闭。没有新增第三方素材，许可证与来源范围不变。
